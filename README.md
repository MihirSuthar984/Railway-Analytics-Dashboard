🚆 Railway Analytics Dashboard | Power BI

📌 Project Overview

The **Railway Analytics Dashboard** is a data visualization project developed using Microsoft Power BI to analyze Indian railway data and present meaningful insights through interactive charts, graphs, KPIs, and maps.

The dashboard helps users understand railway operations, passenger statistics, station performance, train arrivals, and passenger cleanliness ratings. It transforms raw railway data into easy-to-understand visual insights to support data-driven decision-making.

🎯 Project Objectives

- Analyze railway data using Power BI.
- Visualize daily train arrivals and passenger statistics.
- Monitor passenger cleanliness ratings.
- Compare the overall performance of railway stations.
- Present station-related information through map visualizations.
- Build an interactive dashboard for better data analysis and reporting.

🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Microsoft Excel / CSV** — Dataset storage and preparation
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and calculations, where applicable

📊 Dashboard Features

1. Daily Train Arrivals

Visualizes daily train arrival data to help understand railway activity and arrival patterns.

2. Average Daily Passengers

Displays the average number of passengers to understand passenger traffic and station usage.

3. Passenger Cleanliness Rating

Shows passenger feedback about cleanliness to help evaluate station cleanliness and identify areas for improvement.

4. Overall Station Rating

Presents overall station ratings to compare passenger satisfaction and station performance.

5. Railway Station Map

Provides a geographical view of railway stations, making it easier to explore station-related information.

6. Interactive Data Visualization

Uses Power BI visuals and filters to explore railway data and compare available metrics.

🚀 How to Run the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Download the `.pbix` dashboard file.
4. Open the file in Power BI Desktop.
5. If prompted, update the dataset file path.
6. Refresh the data if required.
7. Explore the dashboard using its available filters and visualizations.
